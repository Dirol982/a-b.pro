# a-b.pro — «Альфа Бакалея»

Редизайн сайта [a-b.pro](https://a-b.pro/) в стиле apple.com: статический сайт без зависимостей, готовый для GitHub Pages.

## Страницы

| Файл | Содержимое |
|---|---|
| `index.html` | Главная: hero, направления, категории, хиты продаж, преимущества, партнёры |
| `catalog.html` | Каталог: 52 товара, фильтры по категориям и брендам, поиск, карточка товара во всплывающем окне (`#p-<id>`) |
| `about.html` | О компании, цифры, партнёры |
| `distribution.html` | Производители: ГК «Юг Руси» и ГК «ЭФКО» |
| `contacts.html` | Контакты, карта, заявка, склады, реквизиты |
| `privacy.html` | Политика cookie и персональных данных |

## Как менять

HTML генерируется скриптом из общего шаблона и данных:

```bash
python3 tools/build.py
```

- `assets/data/products.json` — товары (название, бренд, категории, фото, описание). Описания разбираются на штрих-код, кратность, состав, хранение и пищевую ценность.
- `tools/build.py` — шаблон шапки и подвала, тексты страниц, контакты (константы `PHONE`, `EMAIL`, `OFFICE`).
- `assets/css/style.css` — дизайн-система (цвета в `:root`).
- `assets/js/main.js` — меню, анимации появления, счётчики, cookie, форма заявки (открывает письмо на info@a-b.pro).
- `assets/js/catalog.js` — фильтры и карточка товара.

Все изображения взяты с текущего сайта a-b.pro (`assets/img/`).
